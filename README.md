# Tahys Oura Apartment — V1.1 PWA

Esta versão é uma PWA mobile-first e está preparada para instalação no ecrã inicial.

## Teste local
A PWA precisa de HTTPS ou localhost.
No computador, dentro desta pasta:
python -m http.server 8000

Abrir:
http://localhost:8000

No Android/Chrome ou iPhone/Safari, a partir de um endereço HTTPS:
- Android: menu ⋮ → Adicionar ao ecrã principal / Instalar app
- iPhone: Partilhar → Adicionar ao ecrã principal
