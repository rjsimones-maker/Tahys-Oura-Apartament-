# Tahys Oura — Beach Access update

Atualização para o repositório da app.

## Ficheiros a substituir/adicionar
- `app.js` — adiciona Pool Access e Beach Access em My Stay e as respetivas rotas privadas.
- `styles.css` — estilo do cartão do Beach Access.
- `sw.js` — cache V1.8 e inclusão de `beach-access-map.png`.
- `beach-access-map.png` — imagem do percurso apartamento → Praia da Oura Leste.

## Instalação no GitHub
1. Substituir `app.js`, `styles.css` e `sw.js` pelos ficheiros deste ZIP.
2. Adicionar `beach-access-map.png` à raiz do repositório.
3. Fazer commit/push.
4. Abrir a app e, se necessário, limpar o cache/service worker do browser para carregar a V1.8.

A área Beach Access aparece em **My Stay** e requer entrada na área privada.
